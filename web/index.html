iOS 签名与安装
签名由 Mac 完成。iPhone 的开发者模式或“信任”操作不能替代开发证书和设备授权。
  1. 在 Apple 开发者账号登记设备，并更新描述文件。
  2. Mac 使用 Xcode、证书和项目归档导出签名 IPA。
  3. 开发签名通过 Xcode / Apple Configurator 安装；Ad Hoc 分发还需要受设备信任的 HTTPS。
此页面不会要求输入 Apple ID 密码。签名凭据留在 Mac 的 Xcode 与钥匙串中。
登记这台 iPhone / iPad
请在 Safari 打开。下载后到“设置 → 通用 → VPN 与设备管理”确认安装。描述文件可能显示“未签名”，它仅收集 UDID、型号和系统版本，不安装根证书或设备管理。登记成功不等于 Apple 已授权安装。

新建 ILS Release Profile
新项目优先使用 Apple Release Build Contract：项目脚本只负责构建/签名/提交，ILS 负责 Git、任务状态和本地安装包发布。
标准模式：脚本写入 ILS_OUTPUT_DIR/ils-result.json，ILS 验证最终产物后负责发布。
TestFlight lane 由项目脚本上传 App Store Connect；ILS 显示 archive / upload / submitted 状态和实时日志。上传成功不等于 Apple 已完成 Processing。
